# 🎮 Software QA Testing Portfolio 🎮

This repository aims to present bug reports found in games across different platforms, documenting issues clearly with detailed analyses following software quality assurance (QA) technical reporting best practices.

---

## 🛠️ Methodology and Report Structure

Each report was documented using a standardized QA model, containing:
* **Technical Classification:** Severity and priority based on gameplay impact.
* **Environment and Reproducibility:** Platform details, build version, and step-by-step reproduction instructions.
* **Result Analysis:** Clear comparison between *Expected Result* and *Actual Result*.
* **Mapped Evidences:** Media and screenshots stored in the central `/imagens` folder.
